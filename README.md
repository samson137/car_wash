# Fountain Car Wash & Cleaning Hub: Management System

A single-file web app for recording car washes, payments, debts, staff commission,
maintenance fund, daily cash reconciliation and PDF reports.

- Open `index.html` in a browser, or host it with GitHub Pages.
- Data is stored in the browser (localStorage) on the device in use.
- Pricing, maintenance and the 40% staff / 60% business split live in `index.html`
  (`buildCat()` and `eng()`).
